# 02. 화면 인벤토리와 페이지별 요구사항

## 1. 읽는 법

- **UI**: 첫 화면 디자인에 반드시 보여야 하는 핵심 블록
- **기능**: 사용자가 수행하는 핵심 액션
- **연결**: 주요 진입 화면 → 현재 화면 → 주요 이탈 화면
- **상태**: 기본 외 별도로 디자인해야 하는 상태
- **확정도**: C(확정), I(추론), P(정책 필요)

모든 목록 화면은 별도 표기가 없어도 `로딩 / 결과 없음 / 검색 결과 없음 / 오류·재시도 / 권한 없음` 상태를 가진다. 모든 제출 폼은 `초기 / 입력 중 / 검증 오류 / 저장 중 / 저장 성공 / 서버 오류 / 이탈 경고` 상태를 가진다.

### VOD-04 플레이어 상세 구성

```text
상단 집중 헤더
├─ 과정명 / 현재 아이템
├─ 전체 진도와 저장 상태
└─ 학습 종료
본문 2열
├─ Main
│  ├─ Video / Coding / Quiz 콘텐츠
│  ├─ 제목·설명
│  ├─ 자료/교안
│  └─ 내 노트
└─ Curriculum
   ├─ 섹션
   ├─ 아이템 상태(완료/현재/잠김)
   └─ 예상 시간
우측 Overlay
└─ AI 교관 대화
하단
├─ 이전/다음
└─ 완료 처리
```

필수 상태:

- 최초 재생, 이어보기 확인
- 자막 있음/없음, 자료 있음/없음
- 진도 저장 중/저장 완료/오프라인
- 수강 기간 만료, 접근 권한 없음
- 다음 아이템 잠김, 완료 조건 미충족
- 동영상 재생 오류와 대체 안내
