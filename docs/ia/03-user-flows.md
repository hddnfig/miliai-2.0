# 03. 페이지 연결과 핵심 사용자 흐름

## 1. 전체 서비스 구조

```mermaid
flowchart LR
    Public["공개 영역"] --> Auth["인증·온보딩"]
    Auth --> Learner["학습자 워크스페이스"]
    Auth --> Command["지휘관 워크스페이스"]
    Auth --> Admin["운영자 워크스페이스"]

    Learner --> Explore["학습 탐색"]
    Explore --> VOD["VOD 학습"]
    Explore --> PBL["PBL 학습"]
    Learner --> Learning["내 학습"]
    Learning --> VOD
    Learning --> PBL
    PBL --> Peer["동료평가"]
    VOD --> Growth["나의 성장"]
    PBL --> Growth
    Learner --> Community["커뮤니티"]
    Learner --> My["MY"]

    Command --> Unit["부대 학습"]

    Unit --> Support["지원 대상"]

    Admin --> PblAdmin["PBL 관리"]
```

## 2. 신규 학습자 진입

```mermaid
flowchart TD
    A["서비스 홈 PUB-01"] --> B{"계정 보유"}
    B -- "예" --> C["로그인 AUTH-01"]
    B -- "아니오" --> D["회원가입 AUTH-02"]
    D --> E["온보딩 AUTH-03"]
    E --> F{"사전 역량진단"}
    F -- "진행" --> G["역량진단 GROW-03"]
    F -- "건너뛰기" --> H["학습자 홈 HOME-01"]
    G --> I["진단 결과·추천"]
    I --> H
    C --> J{"최초 로그인"}
    J -- "예" --> E
    J -- "아니오" --> H
    H --> K["학습 탐색 EXP-01"]
```

예외:

- 가입 중 소속 부대/계급 조회 실패 → 직접 입력이 아니라 재시도/문의로 제한한다.
- 최초 로그인 이후 온보딩을 중단하면 홈에 `온보딩 이어하기` 배너를 표시한다.
- 보호 화면에서 로그인한 경우 홈보다 원래 목적지로 복귀한다.

## 3. VOD 핵심 흐름

```mermaid
flowchart TD
    A["홈/탐색/검색"] --> B["VOD 목록 VOD-01"]
    B --> C["VOD 상세 VOD-02"]
    C --> D{"로그인·수강 상태"}
    D -- "비회원" --> E["로그인 AUTH-01"]
    E --> C
    D -- "미수강" --> F["수강 신청 VOD-03"]
    F --> G{"승인 방식"}
    G -- "즉시 승인" --> H["VOD 플레이어 VOD-04"]
    G -- "승인 대기" --> I["내 학습 MYL-01"]
    D -- "수강 중" --> H
    H --> J{"아이템 유형"}
    J -- "동영상·자료" --> H
    J -- "퀴즈" --> K["퀴즈 VOD-05"]
    J -- "코딩" --> L["코딩 실습 VOD-06"]
    K --> M{"다음 아이템"}
    L --> M
    H --> M
    M -- "있음" --> H
    M -- "없음" --> N{"설문 필수"}
    N -- "예" --> O["설문 VOD-07"]
    N -- "아니오" --> P["과정 완료 VOD-08"]
    O --> P
    P --> Q["수료증 GROW-05"]
    P --> R["추천 콘텐츠 상세"]
```

VOD 연결 규칙:

| 출발 | 액션 | 도착 | 뒤로가기/복귀 |
|---|---|---|---|
| VOD-01 | 카드 선택 | VOD-02 | 필터·스크롤 유지 |
| VOD-02 | 학습 시작 | 마지막 학습 아이템 VOD-04 | 상세 |
| VOD-04 | 목차 선택 | 선택 아이템 VOD-04/05/06 | 동일 플레이어 컨텍스트 |
| VOD-05/06 | 제출 완료 | 결과 상태 또는 다음 아이템 | 답안/결과 유지 |
| VOD-08 | 미완료 항목 선택 | 해당 아이템 | 완료 화면으로 복귀 가능 |

## 4. PBL 핵심 흐름

```mermaid
flowchart TD
    A["홈/탐색/검색"] --> B["PBL 목록 PBL-01"]
    B --> C["PBL 상세 PBL-02"]
    C --> D{"참여 상태"}
    D -- "미참여" --> E["참여 신청 PBL-03"]
    D -- "참여 중" --> H["워크스페이스 PBL-05"]
    E --> F{"팀 방식"}
    F -- "직접 구성" --> G["팀 구성 PBL-04"]
    F -- "자동 배정" --> G
    F -- "개인 수행" --> H
    G --> H
    H --> I["미션 상세 PBL-06"]
    I --> J["문제 수행 PBL-07"]
    J --> K{"문제 완료"}
    K -- "다음 문제" --> J
    K -- "미션 완료" --> L["미션 제출 PBL-08"]
    L --> M{"다음 미션"}
    M -- "있음" --> I
    M -- "없음" --> N["동료평가 허브 PBL-09"]
    N --> O["동료평가 작성 PBL-10"]
    O --> P{"평가 종료"}
    P -- "대기" --> N
    P -- "완료" --> Q["결과/회고 PBL-11"]
    Q --> R["성장·역량 GROW-01/02"]
```

PBL 상태 전이:

```mermaid
stateDiagram-v2
    [*] --> 신청
    신청 --> 승인: 승인
    신청 --> 취소: 신청 취소
    승인 --> 준비: 팀 구성
    준비 --> 학습중: 시작일 도달
    학습중 --> 평가중: 모든 미션 제출
    평가중 --> 완료: 평가 조건 충족
    승인 --> 취소: 참여 취소
    준비 --> 취소: 참여 취소
    완료 --> [*]
    취소 --> [*]
```

ERD 상태와의 대응:

| 사용자 문구 | 예상 코드 |
|---|---|
| 신청 | `APPLIED` |
| 승인 | `ACCEPTED` |
| 취소 | `CANCELED` |
| 준비 | `PREPARING` / 미션 `STANDBY` |
| 학습 중 | `LEARNING` / 미션 `DOING` |
| 평가 중 | 미션 `DONE` 또는 `EVALUATED` 전 |
| 완료 | `FINISHED` / 미션 `EVALUATED` |

## 5. 동료평가

```mermaid
sequenceDiagram
    participant L as 팀 리더
    participant S as 시스템
    participant P as 동료평가자
    participant M as 팀원

    L->>S: 평가 요청 생성
    S-->>P: 알림 및 마감 안내
    P->>S: 평가 임시저장
    P->>S: 평가 제출
    S-->>L: 진행률 갱신
    S-->>M: 공개 조건 충족 시 결과 알림
    M->>S: 결과/피드백 확인
```

화면 연결:

- 홈의 `평가 마감` 카드 → PBL-10
- 내 학습의 `평가 필요` 탭 → PBL-09
- 알림의 `평가 요청` → PBL-10
- 제출 후 → PBL-09의 완료 상태
- 전체 평가 종료 알림 → PBL-11

## 6. 커뮤니티

```mermaid
flowchart LR
    A["커뮤니티 허브 COM-01"] --> B["게시판 목록 COM-02"]
    B --> C["게시글 상세 COM-03"]
    B --> D["게시글 작성 COM-04"]
    C --> E{"작성자/관리자"}
    E -- "수정" --> D
    E -- "삭제" --> B
    D --> C
    C --> B
```

게시판 유형별 차이:

| 유형 | 목록 | 상세 | 작성 |
|---|---|---|---|
| 공지 | 고정/중요 배지 | 중요도, 첨부 | 운영자 중심 |
| Q&A | 답변 상태, 분류 | 질문과 답변 | 회원 |
| FAQ | 카테고리, 검색 | 접기/펼치기 가능 | 운영자 |
| 뉴스 | 썸네일, 발행일 | 본문/관련 링크 | 운영자 |
| 동료평가 글 | 프로젝트/팀 범위 | 공개 정책 필요 | 시스템 또는 팀 |
| AI 대화 공유 | 컨텍스트/공개 범위 | 대화 스냅샷 | 회원, 정책 필요 |

## 7. 성장·추천 루프

```mermaid
flowchart LR
    Activity["VOD/PBL 학습 활동"] --> Evidence["문항·문제·평가 근거"]
    Evidence --> Skill["역량/스킬 갱신"]
    Skill --> Growth["성장 대시보드"]
    Growth --> Gap["역량 격차"]
    Gap --> Recommend["추천 콘텐츠"]
    Recommend --> Detail["VOD/PBL 상세"]
    Detail --> Activity
    Assessment["역량진단"] --> Skill
```

추천 카드에는 최소한 `추천 대상 콘텐츠`, `관련 스킬`, `현재 수준/목표 수준`, `추천 사유`를 표시한다. ERD의 추천 테이블은 스킬명·설명·레벨을 가지지만 추천 알고리즘과 노출 우선순위는 정책 확인이 필요하다.

## 8. 지휘관 흐름

```mermaid
flowchart TD
    A["지휘관 현황 CMD-01"] --> B{"이상 징후"}
    B -- "참여 저조" --> C["지원 대상 CMD-06"]
    B -- "역량 격차" --> D["역량 분석 CMD-05"]
    B -- "과정 성과" --> E["부대 학습 CMD-02"]
    C --> F["구성원 상세 CMD-03"]
    D --> G["교육 프로그램 CMD-04"]
    F --> G
    G --> H["추천/배정 요청"]
    H --> E
    E --> I["리포트 CMD-07"]
```

개인 상세는 민감도가 높으므로 `본인 소속 범위`, `업무 필요성`, `행동 로그`를 전제로 한다. 권한 미확정 시 UI는 집계 데이터 중심으로 디자인한다.

## 9. 운영자 콘텐츠 제작 흐름

```mermaid
flowchart TD
    A["콘텐츠 목록"] --> B["새로 만들기/복제"]
    B --> C["기본정보"]
    C --> D["구조·아이템 편집"]
    D --> E["학습 조건·수료 기준"]
    E --> F["미리보기"]
    F --> G{"검수"}
    G -- "수정 필요" --> D
    G -- "승인" --> H["게시"]
    H --> I["차수 생성"]
    I --> J["참여자·진도 운영"]
    J --> K["종료·수료 처리"]
    K --> L["보관/복제"]
```

PBL은 `프로젝트 → 미션 → 문제`, VOD는 `과정 → 목차 → 학습 아이템`의 구조 편집기를 사용한다. 두 편집기의 화면 골격은 같게 만들되, 아이템 속성은 분리한다.

## 10. 딥링크·상태 보존 규칙

- 목록 → 상세 → 뒤로가기는 검색어, 필터, 정렬, 페이지, 스크롤을 복원한다.
- 알림 딥링크는 대상이 삭제/종료됐을 때 상위 목록과 사유를 보여준다.
- 플레이어/워크스페이스는 마지막 위치를 저장하고 `이어하기`로 복귀한다.
- 수강 기간 만료 후 학습 URL 접근 시 상세 또는 완료 화면으로 안내한다.
- 운영자 편집 URL에 권한이 없으면 데이터 존재 여부를 노출하지 않고 접근 제한 화면으로 이동한다.
- 외부 공유가 가능한 것은 공개 콘텐츠 상세, 공개 게시글, 수료증 검증 링크로 제한한다.
