# Digital Camouflage

## 상태

| 항목 | 값 |
|---|---|
| Concept ID | `digital-camouflage` |
| 적용 상태 | `provisional` |
| 근거 | 사용자 제공 컨셉 보드와 데스크톱 UI 이미지 |
| 적용 범위 | 디자인 시스템과 신규 구축 화면 전체 |
| 전체 화면 확장 | 임시 테마로 즉시 적용, 최종 승인 전 교체 가능 |

이 컨셉은 현재 유력 후보지만 확정안이 아니다. 구조와 분리된 테마 패키지로 관리한다.

## 디자인 원칙

1. **Signal over decoration**: 라임은 중요한 행동, 현재 위치, 연결 상태에만 사용한다.
2. **Layered darkness**: 검은 배경 안에서 표면 명도, 얇은 경계, 추상 패턴 레이어로 계층을 만든다.
3. **Tactical clarity**: 군사 모티프는 장식이 아니라 탐색, 상태, 포커스 표현에 사용한다.
4. **Dense but legible**: 정보 밀도는 높게 유지하되 제목, 메타데이터, 행동 영역을 명확히 분리한다.
5. **Replaceable imagery**: 지형·카모플라주 자산은 초기 화면부터 적극 사용하되 테마 전용 슬롯으로 격리한다.
6. **Kinetic by default**: 핵심 배경과 미디어 슬롯에는 저강도 앰비언트 모션을 적용하며, 감소된 모션 환경에서는 정지한다.

## 관찰과 추론

### Direct

- 오프블랙 전체 배경과 검은 반투명 표면
- 네온에 가까운 산성 라임 단일 강조색
- 흰색 제목과 회색 보조 텍스트
- 좌측 고정 내비게이션과 넓은 본문
- 지형 포인트 클라우드 및 연결 경로 배경
- 픽셀형 디지털 카모플라주 모티프
- 모서리 브래킷 형태의 포커스 프레임
- 작은 반경, 얇은 경계, 낮은 그림자 의존도
- 고밀도 카드, 짧은 메타데이터, 명확한 CTA

### Inferred

- 본문 산세리프는 한글 가독성이 높은 중립적 계열을 사용
- 모션은 배경의 저강도 흐름, 탐색 경로, 상태 변화에 사용
- 라임 발광 효과는 배경 노드에만 허용하고 일반 버튼에는 제한
- 데이터 화면은 카드 남용보다 표면 명도와 구획선으로 분리
- 모바일에서는 배경 자산을 약화하고 콘텐츠 대비를 우선

### Unresolved

- 최종 로고 원본과 보호 공간
- 브랜드 지정 서체
- 그래픽 에셋별 적정 밀도와 페이지군별 변형 수
- 다크 단일 테마인지 라이트 변형도 필요한지
- 지형 배경의 최종 제작 방식과 애니메이션 범위
- 관리자 고밀도 표의 확정 시각 규칙

## 자산 매니페스트

| 자산 | 상태 | 용도 | 교체 조건 |
|---|---|---|---|
| `terrain-network-v1.png` | generated provisional | 핵심 히어로·검색·포커스 영역의 키네틱 배경 | 선호도 검토 또는 최종 컨셉 자산 수령 시 |
| `camo-texture-v1.png` | generated provisional | 전체 배경·카드 미디어 슬롯의 낮은 대비 패턴 | 선호도 검토 또는 최종 컨셉 자산 수령 시 |
| MILI AI logo | missing source | 내비게이션과 인증 | 원본 SVG/PNG 필요 |
| Photorealistic people/objects | prohibited | 사용하지 않음 | 정책 변경 시에만 재검토 |
| Device mockup | not required for product UI | 컨셉 발표 자료 | 제품 화면에는 사용하지 않음 |

생성 자산은 사용자 제공 이미지를 스타일 참고로 사용했으며, UI·로고·텍스트·인물·기기를 복제하지 않았다.

## 적용 범위

### 지금 적용

- 시맨틱 색상과 표면 토큰
- 반경, 경계, 포커스, 간격 원칙
- 액션·배지·패널의 대표 상태
- 테마 자산 슬롯
- 추상 지형·카모 패턴의 화면별 배치
- 저강도 키네틱 배경과 모션 감소 대응
- 디자인 시스템 카탈로그

### 컨셉 확정 후 적용

- 최종 타이포그래피
- 최종 로고
- 그래픽 에셋 품질·변형·모션의 최종 고도화
- 라이트 테마 또는 대체 접근성 테마

## 롤백

`data-theme="digital-camouflage"`를 다른 테마 ID로 변경하면 화면 구조를 유지한 채 테마를 교체할 수 있어야 한다. 화면 컴포넌트에서 이 컨셉의 색상 코드나 이미지 경로를 직접 사용하면 안 된다.
