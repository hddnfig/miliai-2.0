# miliai-2.0


# 작업 완료 후 AI에게 시킬 검수 프롬프트
## 검수 항목

### 1. 작업 범위

* 요청받은 범위를 벗어난 수정이 있는지
* 관련 없는 파일이 변경되었는지
* 불필요한 리팩터링이 포함되었는지
* 기존 공통 컴포넌트를 중복 구현했는지

### 2. Git 변경사항

* 기준 브랜치에서 정상적으로 분기했는지
* 커밋에 불필요한 파일이 포함되었는지
* lock 파일이나 설정 파일이 불필요하게 변경되었는지
* 충돌 가능성이 높은 공통 파일을 과도하게 수정했는지

### 3. 코드 품질

* 타입 오류 가능성
* 런타임 오류 가능성
* 중복 코드
* 하드코딩
* 불필요한 상태
* 불필요한 렌더링
* 예외 처리 누락
* 사용하지 않는 코드와 import
* 기존 코드 컨벤션 위반

### 4. UI 및 UX

* 디자인 시스템과 다른 스타일 사용 여부
* 공통 컴포넌트 재사용 여부
* hover, focus, active, disabled 상태
* 로딩, 에러, 빈 상태
* 모바일 및 데스크톱 반응형
* 긴 텍스트와 데이터 예외 상황
* 키보드 및 스크린 리더 접근성

### 5. 보안

* API 키와 민감 정보 노출
* 사용자 입력 검증 누락
* 권한 검증 누락
* 보안상 위험한 코드
* 로그에 개인정보가 포함되는지

### 6. 검증

가능하다면 다음 명령을 실행하세요.

* 타입 검사
* 린트
* 테스트
* 빌드

실행하지 못한 항목은 실행하지 못했다고 명시하세요.

## 결과 형식

### 반드시 수정해야 하는 문제

PR 생성 전에 해결해야 하는 문제를 작성하세요.

### 개선을 권장하는 문제

현재 기능은 동작하지만 개선할 가치가 있는 내용을 작성하세요.

### 변경 범위 이상 없음

문제가 없다면 확인한 근거를 작성하세요.

### 테스트 결과

실행한 명령과 결과를 작성하세요.

### PR 작성 시 주의사항

리뷰어에게 알려야 할 내용과 충돌 가능성을 작성하세요.

문제를 발견하더라도 자동으로 대규모 수정하지 말고, 수정 대상과 수정 방안을 먼저 제안하세요.
